How to put it on the Basys 3
  1. Plug a monitor into the Basys 3 VGA port.
  2. In Vivado, make a project for xc7a35tcpg236-1 and add sources/design sources/vga_modules.v as a design source. It already contains vga_controller, so don't add vga_controler.v as well.
  3. Add sources/Constraints/Basys3_Master.xdc as the constraints file.
  4. Draw your design here, choose Full top module and copy it.
  5. Paste it into a new design source, set it as the top module, and generate the bitstream.
